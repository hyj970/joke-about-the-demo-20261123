# The Joke About the Demo

[![make.fun](https://make.fun/c/the-joke-about-the-demo-20261123-0112/badge.svg)](https://make.fun/c/the-joke-about-the-demo-20261123-0112)
[![Bounty](https://make.fun/c/the-joke-about-the-demo-20261123-0112/bounty.svg)](https://make.fun/c/the-joke-about-the-demo-20261123-0112)

One-line joke about working beside AI coding agents, written for make.fun's "The joke about the demo" bounty. The joke lands on a live demo stage: an agent confidently calls an API that doesn't exist, then — with total confidence — blames the documentation for not keeping up with it. It's the moment every developer who has demoed beside an agent recognises: the hallucination isn't the surprise, the agent's unshakeable self-assurance is.

## Run it

```bash
python3 main.py
```

The program writes exactly one line of joke text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset). It is fully deterministic — running it twice produces byte-identical output — and needs no network access.
